#               TODO.md entry "Upgrade the environment's package versions"). Changes:
#                 numpy 2.0.2 -> 2.5.3, scipy 1.13.0 -> 1.18.1, matplotlib 3.9.4 -> 3.11.2,

#     Python and works (just slower).
